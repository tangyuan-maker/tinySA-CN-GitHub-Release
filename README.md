# tinySA 中文固件

本项目基于原版 tinySA 固件进行中文界面适配，旨在为中文用户提供更易理解的菜单、操作提示和使用体验。

本项目沿用原版 tinySA 的构建环境和编译流程。编译前请先阅读原项目文档，并根据对应硬件型号配置开发环境。

## 使用说明

1. 下载对应版本的完整源码或发布文件。
2. 阅读该版本的使用说明。
3. 确认设备型号及固件兼容性。
4. 刷写前备份原有固件，并确认文件来源及刷写步骤正确。

刷写固件存在设备无法正常启动的风险，请谨慎操作。
